*sphere.txt* Sphere Route Manual (Neovim WASM) ============================================================================== 1. MOVEMENT COMMANDS *commands* forward({deg}); Move forward {deg} degrees across the sphere. Short alias: fd({deg}); Range: 0 < {deg} <= 360. turn({deg}); Turn left or right by {deg} degrees. Short alias: t({deg}); Positive = turn left (counterclockwise). Negative = turn right (clockwise). ============================================================================== 2. STANDARD MATH LIBRARY () *cmath* Standard C++ math functions are available directly: pow(base, exp) Computes base^exp (e.g. pow(2.0, 3.0) == 8.0). sqrt(x) Square root of x. abs(x) Absolute value of x. sin(x), cos(x), tan(x) Trigonometric functions (radians). asin(x), acos(x) Inverse trigonometric functions. atan2(y, x) Two-argument arctangent. floor(x), ceil(x) Rounding functions. min(a, b), max(a, b) Minimum and maximum. M_PI Constant pi (3.141592653589793). Both `pow(...)` and `std::pow(...)` are supported. ============================================================================== 3. COMMANDS & SHORTCUTS *shortcuts* Run code and navigate levels with standard Neovim commands: :Run, :R Run path on the sphere. r, r Run path (Normal mode). Run path (Normal & Insert mode). Run path without leaving Insert mode. :Manual, m, Open this reference manual. :Next, n Go to next level (when passed). :Prev, p Go to previous level. All official Neovim commands (:w, :help, :q, hjkl, motions) remain standard. ============================================================================== 4. C++ CODE EXAMPLE *example* Standard C++ functions, loops, and variables are supported: #include <sphere.hpp> #include <cmath> void path() { double dist = 60.0; for (int i = 0; i < 3; ++i) { forward(dist); turn(90.0); } }
