*rihla.txt* Spherical Path Studio Manual (Neovim WebAssembly Edition) ============================================================================== 1. C++ SPHERICAL PRIMITIVES *primitives* forward({deg}); Walk {deg} degrees along the current great circle. Also aliased as: fd({deg}); Constraint: 0 < {deg} <= 360. turn({deg}); Rotate heading inside the local tangent plane. Also aliased as: t({deg}); Positive = left (counterclockwise). Negative = right (clockwise). ============================================================================== 2. STANDARD MATH LIBRARY () *cmath* The standard C++ math functions are available directly: pow(base, exp) Computes base^exp (e.g. pow(2.0, 3.0) == 8.0). sqrt(x) Square root of x. abs(x) Absolute value of x. sin(x), cos(x), tan(x) Trigonometric functions (radians). asin(x), acos(x) Inverse trigonometric functions. atan2(y, x) Two-argument arctangent. floor(x), ceil(x) Rounding functions. min(a, b), max(a, b) Minimum and maximum. M_PI Constant pi (3.141592653589793). Both bare `pow(...)` and `std::pow(...)` namespaces are supported. ============================================================================== 3. GENUINE NEOVIM WEBASSEMBLY *neovim* Running native compiled Neovim WebAssembly via WASI/Emscripten. :w, :write Compile and execute the path on the sphere. :n, :next Advance to the next waypoint (if verified). :p, :prev Navigate back to the previous waypoint. :h, :help Open this reference manual buffer. :q Close this reference manual buffer. Execute path without leaving Insert mode. ============================================================================== 4. C++ CONTROL FLOW & SYNTAX *syntax* Standard C++ functions, loops, and variables are supported: #include <rihla.hpp> #include <cmath> void path() { double radius = pow(2.0, 5.0); // 32 degrees for (int i = 0; i < 3; ++i) { forward(radius); turn(90.0); } }
